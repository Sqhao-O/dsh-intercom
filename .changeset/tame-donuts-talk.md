Cross-process intercom: broker transport over local socket/named pipe with auto-spawn and reconnect, full tool action set (ask/reply/pending/cancel/list-cwd), reply tracker, offline mailbox with name+cwd redelivery rules, config file ($DSH_HOME/intercom/config.json) with fail-closed parsing, and lost-wake redelivery watchdog for inbox injection.
